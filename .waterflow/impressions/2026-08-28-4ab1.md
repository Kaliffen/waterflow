Unborn: the value of `revision` on a record emitted when no commit yet exists to
anchor it. It is a stated absence, not a revision, and never reads as fresh.

Avoid: leaving the field blank, and writing a hand-rolled comment beside a real
sha. Both were in use in the crowd-sim store, and both are indistinguishable at
a glance from an anchor that simply has not drifted.

The word is borrowed from git's own name for a branch with no commits, which is
exactly the state it describes, so it costs a reader nothing to learn. It shares
a reporting path with an unreachable anchor: both are freshness unknown, because
in both cases the record's claim cannot be checked against anything.
