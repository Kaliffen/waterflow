A goal could not legally be written: the field table required an `atom` on every
record while the kinds section said no atom emits a goal, so the one kind the
owner adds by hand was the one kind the contract forbade.

Two axes over twelve commits, both joined. Fixed at 9605f9f.

**The contradiction spec found is the shape to remember.** Each half was written
in a different commit, each was right on its own, and nothing between them ever
read both. A per-commit review cannot find that class of defect, and this is the
third time in this session an integration pass has found one the slice passes
missed.

**`recall` was left behind twice.** Its unproven query filtered on `kind` alone
-- the exact silent-success failure the fold warns about, in a store where
thirty-two of thirty-eight records carry no kind -- and its report had four
groups for five kinds, so a live watermark had nowhere to go. The fold had been
taught the legacy fallback one commit earlier and the third site never got it.

**The fold described a move with no operation.** Every other behaviour in the
contract ships a runnable snippet; this one shipped a verb. It now derives the
path, finds watermarks both ways, and uses `git mv` so the move stays a rename.

**Two live prove records for one subject**, which is the eviction failure the
contract calls the sediment it exists to prevent, in the store meant to
demonstrate it.

**The close that was withdrawn.** Spec called store-ontology-4f7c the one
dishonest close and was right. The item is written as behaviour -- traces are
cleared away -- and nothing has ever cleared a trace; the proof was a critique
of prose. It is open again and closes when a fold runs.

**Declined, and recorded as a goal instead.** Spec argued that shipping while
this store is eighty-four per cent non-compliant is indefensible on AGENTS.md's
own terms. The mitigation is real -- both readers classify kind-less records by
atom -- but it is compatibility, not demonstration. Backfilling the field across
thirty-two landed records would be curation the contract forbids and would put a
field on records nobody re-derived. Consolidation retires them as subjects
finish, so the gap is a target, not a defect: 2026-08-29-a1d8.
