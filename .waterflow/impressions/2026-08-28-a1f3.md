The atom's one-line report is specified in the emission contract, not in the ten
atoms: an atom reports and emits in the same beat, so the rule lives where the
atom already looks.

Supersedes 2026-08-28-9a02, which settled the reporting shape but left the atom
half homeless. Everything in it still holds: atoms end with a one-line report,
composites with a fixed-shape block, five markers and no ANSI, a row per atom
including skipped ones, and agents dispatched and joined counted in the block.
Only the question of where the atom rule is written is new.

Owner chose the emission contract over two alternatives. Writing a sentence into
each of the ten atoms was rejected as the shotgun surgery the critique had just
flagged, and it spends prose budget in every shipped skill for a rule that never
varies. Stating it in reporting.md and the router and letting atoms inherit it
silently was rejected because nothing would carry it to the point of use.

impressions.md is the right home because every atom already loads it at the
moment it finishes an operation, which is exactly when the line is due. The
cost is one paragraph in one file and no prose in any skill. The gain is that
reporting and emitting stop being two rules an atom has to remember separately.
