The anchoring fix missed the records it was written for: `land` re-anchored only
what the landing run proved, and the five mis-anchored records in the field run
were emitted by earlier build runs.

Supersedes 2026-08-28-8a3c. Two axes, both dispatched and joined, seven findings,
all repaired at fb92a92.

**The one that mattered.** Spec traced the new `land` wording literally against
the field repo and found it excluded its own target. Records are emitted and
items closed *during* the build, when `HEAD` is still the commit the work started
from; a landing run proves nothing about them, so "the records this run proved"
named the one category that was already correct. The rule now covers every
record and item in the work being landed, and says that is most of them.

**The check did not check what the prose claimed.** `git log --oneline
--diff-filter=A` prints commit subjects, so "output covering the whole scope"
could not be read from it, and it fired when any single path in scope was added.
Now `--name-only --format=` lists the paths, `scope: []` is exempt as it is from
staleness, and the command was run against the field repo before this record was
written: it names both paths of a mis-anchored record and stays silent on a
correctly anchored one.

**A marker that collided.** `critique` had grown an instruction to mark axis
independence `⚠️` when running inline. There is no such field, and `⚠️` in a
critique row already means findings were found -- so an inline run with nothing
to report would have emitted a symbol meaning the opposite. The declaration was
what 2026-08-29-a7f1 asked for; the marker was invented alongside it and is gone.

**On the store's own hygiene.** Standards caught the field proof breaking a
six-record supersession chain by claiming the same subject with a different kind
of evidence, and its gist running to two sentences. It now carries its own
subject, `field-proof`, which is honest: `npm test` and driving a real app
through the flow are not the same claim about the same thing.

**Both axes ran as dispatched subagents.** Dispatched 2, joined 2.
