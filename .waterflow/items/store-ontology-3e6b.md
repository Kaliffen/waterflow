A query returns what is true and what governs the area, and separates the things
believed on a single sighting from the things that were checked. It can be asked
for that unverified set on its own, which is the list of what the subject would
have to prove to be sure of itself. A target nobody has measured is reported as
unmeasured rather than as met.
