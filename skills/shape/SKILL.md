# Shape

Run these atoms in order. Do not restate their rules here.

1. **`recall`** the subject. If there are no live `define` or `interrogate`
   records, the work is not settled — run `align` first.
2. **`seam`** — choose where behaviour will be observed, and confirm it.
3. **`slice`** — cut vertical tracer bullets with blocking edges, confirm the
   breakdown, publish to the state surface.

Use **`probe`** when a slice depends on a design question nobody can answer on
paper, and **`dig`** when it depends on a fact from outside the repository.
Both run before slicing, not during it.

**Done when** `list_frontier` returns at least one item that can start now, and
a seam record exists for the subject.

Next: `build`.

**Report** the block before moving on:
[reporting.md](../waterflow/references/reporting.md).
